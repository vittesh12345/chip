ORBIT-AI v0.1 concept budget (model/concept_budget.py)
========================================================================
Calculated bounds from the brief's stated assumptions. No measurement,
benchmark, power estimate or thermal simulation is represented here.

Assumptions
------------------------------------------------------------------------
  tiles x array               16 x 32 x 32 = 16384 INT8 MACs
  ops per MAC                 2
  clock range                 200 MHz - 800 MHz (no timing measurement)
  local SRAM                  32 MiB usable, 2 MiB per tile, SECDED 64+8
  external memory             16 GiB+ at 256 GB/s (decimal GB)
  power allocation            40 W (sizing allocation, not an estimate)
  die-to-radiator resistance  0.5 K/W
  radiator                    emissivity 0.9, sigma 5.670374419e-08 W/m2/K4, 0 K view
  thermal thresholds          recover 70 C, throttle 80 C, stop 95 C
  local input per tile        64 bytes/cycle (32 row + 32 column INT8 operands)
  matrix-vector intensity     2 ops per weight byte (one MAC per byte)
