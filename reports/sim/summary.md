## Limitations

- Fault-free behaviour only: no upsets are injected here (fault injection is another area), so `fault` and `therm_repair` are only checked to stay 0 and the mismatch/fault-stop path is not exercised by these benches.
- The thermal unused code 3 cannot be reached through the ports without an upset, so its "behaves as STOP" rule is only in the reference models, not observed.
- Gate-level runs are zero-delay functional simulations (no SDF timing).
- Coverage is event counting in the testbench, not simulator code or toggle coverage.
- The random stimulus is constrained by the choices in `tb/cocotb/test_orbit_random.py` (e.g. temperature regimes, sum lengths); the mutation table is evidence that it is sensitive, not a proof of completeness.
- `rst_n` is asserted only a few times mid-run in the random test; reset during an output transfer is covered only if the random run happens to do so.
